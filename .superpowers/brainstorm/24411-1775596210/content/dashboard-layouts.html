Quel layout de dashboard ?

Choisissez la structure qui vous parle le plus

A — Sidebar + Widgets

Navigation verticale à gauche, dashboard en grille de widgets redimensionnables. Style Grafana. Chaque section (Unraid, Réseau, Hôtes) dans un onglet dédié.

B — Topbar + Vue unique

Navigation horizontale en haut, tout sur une seule page scrollable avec sections distinctes : état Unraid, carte réseau, liste d'hôtes. Vue d'ensemble immédiate.

C — Sidebar + Detail panel

Navigation à gauche, contenu central, panneau de détail contextuel à droite qui s'ouvre au clic (hôte sélectionné, conteneur, VM). Style Portainer/VSCode.

Cliquez pour sélectionner, puis répondez dans le terminal
